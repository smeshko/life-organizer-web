Design Directions

Three layout philosophies for the same Transactions view. Same palette, same typography, different spatial strategies.

Command Center

Maximum information density. Icon-only sidebar saves horizontal space. Compact stat cards, tight table rows, monospace everywhere. For the user who wants everything visible without scrolling — like a Bloomberg terminal for personal finance.

Navigation

52px icon-only sidebar with active indicator bar. Logo is a branded monogram. Maximizes content width for wide tables and grids.

Data Density

5px row padding, 9–11px type scale, abbreviated badges (EXP/INC/SAV). 10+ rows visible without scrolling. Monospace dates and amounts.

Best For

Budget planning grid view — where every pixel matters. The 80-category × 12-month grid needs this density to avoid horizontal scroll.

Journal

More breathing room, editorial feel. Wider sidebar with quick-stats. Large Instrument Serif page title. Card-based sections. Feels like opening a beautifully typeset financial diary, not a spreadsheet.

Navigation

240px sidebar with labeled nav items and inline quick-stats at bottom. Always shows monthly summary without navigating away.

Content Cards

Each content section wrapped in a card with header and metadata. Stat cards with top-border color coding. More visual hierarchy through whitespace.

Best For

Spending visualization and budget vs actual views — where charts and comparison data benefit from generous spacing and clear grouping.

Hybrid

Balance of density and breathing room. Floating filter bar always visible. Tabbed content areas. Collapsible sidebar for when you need more space. The pragmatic middle ground.

Navigation

180px sidebar — compact labels, collapsible to icon-only mode. Page title and filters live in a sticky floating bar, always accessible.

Content Tabs

Tab bar filters by transaction type without changing URL or adding filter widgets. Inline stats replace card-based stats for less vertical space usage.

Best For

Versatile across all views. The collapsible sidebar adapts — wide for spending charts, narrow for the budget grid. Tabs work for all views.
